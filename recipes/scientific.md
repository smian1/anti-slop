# Recipe: scientific writing

Register notes for manuscripts, abstracts, grants, discussion, peer-review responses — plus science blogs when formality fits.

## Register

- Domain terminology is precision, not jargon (*weighted interval score*, assay names). Cut business buzzwords and AI vocab (*delve*, *tapestry*, *landscape*, *leverage*) leaking into technical prose.
- Use **we** for own work. Cite specific authors — not "researchers have shown."
- Avoid distant narrator ("It has long been recognized that…") and bloggy pep talk.
- **Passive OK in Methods** when actor is standard/unknown ("samples were centrifuged at…"). Prefer active elsewhere with human/team subjects.
- State claims; back with citations. No weasel attribution.

## Cuts that show up in science drafts

| Before smell | After |
|--------------|-------|
| It's worth noting that these findings have important implications… | Name the specific implication for the method/data |
| Despite these challenges, this work contributes meaningfully… | Cut formula; say what was measured |
| highlighting the need for continued evaluation | Mechanism or next experiment |
| quietly / fundamentally reshape | Cut magic adverbs; scope the claim |
| invented concept labels ("the X paradox") | Plain description |
| patronizing analogies | Direct explanation for the audience |

## Still apply globally

- No em-dash habit; parentheses fine.
- No summary-recap "In conclusion" that only restates abstract.
- No false agency ("the model learns to…" when you mean "we trained…").
- Evidence-bound: do not invent p-values, N, effect sizes, or citations.
- Wh-openers: soft preference only — real research questions stay.

## Publish gate

Optional density questions in `references/eval.md`. Prefer clarity for reviewers over "sounds human" theater.
