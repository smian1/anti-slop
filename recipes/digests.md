# Recipe: digests / video summaries

Write-from-scratch digest shape. Brief ≠ artifact.

## Shape

1. **Title** — what it is, sentence case, no emoji.
2. **Who** — speaker, guests, org — names only if known.
3. **Length** — duration or word count if known.
4. **What happened** — facts in order of usefulness. Names, numbers, timestamps.
5. **Quotes** — only when the wording is the point; quote accurately or paraphrase with attribution.
6. **Caveats** — only when they change how to use the information.
7. **Stop** — no lesson-of-the-story, no "key takeaways" triad, no fake-profound closer, no "In conclusion."

## Rules

- Lead with the fact. Draft mode: no What changed section.
- Portability test on every sentence — specific to *this* video/thread.
- Invent no claims the source didn't make. If unclear, say so or ask.
- No em dashes. Parentheses OK for asides.
- Strip chatbot residue and decorative bold.
- Instructions about the digest stay out of the digest.

## Anti-patterns

- "Here are the key insights…" throat-clearing.
- Synonym cycling the same product/person under three labels.
- Importance puffery ("pivotal discussion", "must-watch").
- Summary-recap final paragraph that restates the digest.
