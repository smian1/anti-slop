# Recipe: org copy (memos, docs, announcements)

Surgical Edit + Evidence-bound. No soul injection.

## Defaults

- Prefer **Edit** + **Evidence-bound** when source is vague.
- Active voice; name owners when the source names them — never invent.
- No em dashes unless a house sample uses them.
- Sentence-case headings. No emoji headings. No decorative bold.
- Semicolons OK. Parentheses OK.
- Long prose: prefer connected sentences over parataxis stacks.

## Must not invent

Roadmaps, headcount, metrics, customer names, legal commitments, "we will…" process promises, security/resilience adjectives unless source states them.

## Cuts

Puffery, weasel attribution ("leadership believes"), binary contrast templates, summary-recap endings, importance-flagging, rule-of-three padding, metaphor jargon (substrate/north star/flywheel) → concrete mechanism.

## What changed

For Edit: list pattern category per change so stakeholders can review. Facts untouched.
