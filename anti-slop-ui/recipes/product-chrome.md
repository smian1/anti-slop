# Recipe: Product chrome

Signed-in UI: shells, dashboards, settings, tables. Built around the job, not the template.

## Defaults

- **Edit** default: minimum visual change; preserve routes and real data.
- Name the screen's job and the one decision the user makes — then hierarchy.
- Tokens/DESIGN.md for color, type, radius. Status colors only on status.
- Dense is fine when information density is the product.

## Cuts that matter most here

Default sidebar + 4 equal stat cards + chart + table before the job is clear; fake metrics and deltas; Jane Doe activity feeds; nested card stacks; glow on every tile; side-tab stripes without state; emoji in nav; Inter-everywhere; infinite skeleton pulse as personality.

## Keep / prefer

- Real numbers or labelled placeholders (`—`, `No data yet`, field hints)
- Empty/loading/error that name cause + next action
- Focus-visible and keyboard paths
- Tables with deciding columns first; menus only for real actions
- Flat surfaces; elevation when stacking matters

## Don't

- Fabricate activity, avatars, or "+12% WoW" without a series
- Chart without a question in the title
- Glassmorphic nav + cards + modals all at once
- Decorative monospace labels on every meta string

## Detect shape

Pattern · file/component · fix. Prefer Evidence-bound honesty over prettier fiction.
