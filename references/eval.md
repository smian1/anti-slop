# Eval checklist

Run after Edit/Draft before returning. Answer pass/fail. Fix failures. Use this checklist only — do not mix competing numeric scales from other tools.

## Core

1. Preserves point — no added claims, examples, stats, quotes, opinions?
2. Preserves distinctive voice (vocab, cadence, bluntness, humor, uncertainty, digressions, polish)?
3. Leaves strong human sentences alone — no rewrite-for-consistency?
4. Cutting proportional to actual slop — no aggressive character strip?
5. Leads with what the reader needs; keeps personal setup that adds context/character?
6. Concrete facts, protected details, direct verbs where the draft supports them?
7. Portability test passed — generic sentences cut or made subject-specific?
8. Active voice with human subjects where possible; false agency killed; passive OK if actor unknown?
9. Useful edge kept; structure preserved unless it hurt the piece?
10. Tangled sentences fixed; clear spoken cadence/fragments kept?

## Words and patterns

11. Banned words / empty phrases / chatbot residue removed (unless quoted)?
12. Empty adverbs cut; voice-bearing (*actually*, *honestly*, *I think*) kept?
13. Binary contrasts, negative listings, rhetorical setups, throat-clearing gone?
14. Faux-insight, colon drama, -ing puffery, fake-strong verbs, synonym cycling, fragment stacks, robotic rhythm fixed?
15. Weasel attribution → named source or flagged for user?
16. Metadiscourse / importance-flagging / demonstrative kickers removed?
17. Fake-profound kickers deleted (not rewritten into better metaphors)?
18. Summary-recap endings cut — ends on concrete point or next action?
19. Formatting slop removed (emoji headings, decorative bold, title case, bullets that should be prose)?
20. Em dashes: none in short copy; sample may allow in long essays; parentheses OK?

## Mode-specific

21. **Edit:** full draft + short **What changed** with pattern categories?
22. **Detect:** each finding = pattern name + quoted line + short fix; no rewrite/score/authorship claim?
23. **Evidence-bound:** no invented owners/metrics/workflows/promises; brief not reprinted?
24. **File:** code/YAML/data/links untouched?

## Final read

25. Avoids robotic symmetry and stacked punchy fragments?
26. Would the writer recognize this as their voice?
27. Would it sound natural read to a sharp colleague?

## Optional publish density questions (soft gate)

Use only when user asks for a publish gate. Qualitative; no mandatory score total.

| Question | Look for |
|----------|----------|
| Directness | Statements or announcements? |
| Rhythm | Varied or metronomic? |
| Trust | Respects reader intelligence? |
| Authenticity | Sounds like a specific human? |
| Density | Anything still cuttable? |

If several answers are weak, revise once more. Do not fail a piece solely on a self-assigned number.
