# Evidence-bound mode

Use when the source is vague marketing, support, incident, recruiting, product, or strategy copy — or when Draft/Edit would otherwise invent concreteness.

## Contract

Concrete detail is an improvement only when licensed by the source, supplied context, or an explicit request for labeled placeholders. Density cannot come from fictional specificity.

Label before adding:

| Label | Meaning |
|-------|---------|
| `source` | Directly in the draft or supporting material |
| `inference` | Narrowly follows without new facts |
| `placeholder` | Useful slot user must verify — `[owner]`, `[deadline]` |
| `unsafe` | Plausible but unsupported — **leave out** |

## Brief ≠ artifact

Instructions about the piece ("keep that texture", "don't promise it can't recur", "the note should stay short") address the agent, not the reader. Do what they ask. Do not reprint them into the output. Reprinting the brief is the same class of error as inventing content.

## Allowed moves

- Narrow inflated claims to what the source actually says.
- State that a claim needs proof instead of inventing proof.
- Bracket slots: `[specific deadline]`, `[owner]`, `[customer-visible change]`.
- Ask for the missing facts.
- Offer a labeled hypothetical **outside** final copy.

## Blocked moves

| Domain | Do not invent |
|--------|----------------|
| Support | Teams, outages, invoices, deadlines, amounts, ownership, "we will review/follow up/resolve" unless source says that action is available |
| Recruiting | Employers, projects, levels, tools, candidate strengths |
| Incidents | Services, durations, failure modes, user impact, remediation steps; quality labels like "secure/resilient/auditable" unless stated |
| Product / marketing | Dashboards, tabs, integrations, analytics, automations, metrics, outcomes, "faster decisions / better alignment / reduced friction" as asserted facts |
| Strategy | Quarterly plans, staffing, budget, owners, governance rules |

## Laundering ban

Do not polish abstract benefits into confident claims. If the source only gives category language ("workspace intelligence"), name the missing mechanism, owner, metric, or evidence — do not assert capabilities.

## Preserve

Named entities, numbers, dates, URLs, citations, quotes, causal claims, scope limits, explicit uncertainty, and the user's stance. Qualifiers that carry risk/legal/technical meaning stay.
