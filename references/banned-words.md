# Banned words and phrases

Cut unless quoted as examples or discussing the word itself.

## Vocabulary — cut

delve, foster, leverage (verb), utilize, facilitate, empower, streamline, robust (non-engineering), cutting-edge, paradigm shift, game changer / game-changing, this is huge, this changes everything, tapestry, realm, beacon, multifaceted, meticulous, intricate / intricacies, paramount, transformative, elevate, embark, supercharge, harness, ever-evolving, landscape (figurative), testament (to), vibrant, pivotal, crucial (as filler), underscore / underscoring, interplay, bolster, garner, commence, encompass, groundbreaking, seamless, navigate (figurative), showcase / showcasing, highlighting (puffery), unprecedented, profound (filler), synergy, pain points, value add, thought leadership, spearheading, aforementioned, endeavour/endeavor.

## Tech metaphor jargon — prefer concrete

substrate → base; wedge → add / entry; vector → way / method; locus / vantage / nexus → the real place or view; primitive (as noun) → name the thing; harness (metaphor) → use; surface ("API surface") → API / endpoints; bedrock / scaffolding (metaphor) → foundation / structure with a real name; modality / paradigm → mode / approach; gold-plating → more than the job needs; ratchet (metaphor) → limit that only tightens / real mechanism name; evacuate (for moving code) → move out; endgame → last phase; north star → goal; flywheel → say the loop.

## Empty adverbs — cut when empty; KEEP when voice

Often empty: just, literally, simply, truly, fundamentally, importantly, crucially, inherently, inevitably, genuinely, deeply, structurally.

**Keep** when they mark real emphasis, contrast, or spoken rhythm: *actually*, *honestly*, *I think*, *maybe*, *to be honest*.

No absolute adverb ban.

## Empty phrases — cut

it's worth noting, it's important to note, at the end of the day, when it comes to, at its core, in today's world / age / world of, the reality is, the truth is, in terms of, with regard to, in order to → to, going forward, in this article, let's dive in / delve into, without further ado, in a nutshell, buckle up, take it to the next level, unlock the power of, bridge the gap, move the needle, the bottom line is, whether you're a X or a Y, from X to Y (meaningless range opener), firstly/secondly/thirdly stacks.

## Chatbot / email residue — cut

I hope this helps!, Let me know if you need anything!, Of course!, Certainly!, Great question!, You're absolutely right!, Found the smoking gun!, As an AI…, As a language model…, I'd be happy to…, Please don't hesitate to reach out, I hope this finds you well / email finds you well, As per my last email (unless genuinely needed).

## Sentence openers — prefer not to start with

Certainly, Absolutely, Sure, Moreover, Furthermore, Additionally, Interestingly, Notably, Importantly, Indeed — especially stacked.

Model-first-word tells (DETECT signal, not a writing recipe): avoid defaulting reply starts to "Certainly," "Sure," "Great question!", "Here is…", "Title:", "Step:", "Creating…".
