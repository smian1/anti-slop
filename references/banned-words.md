# Banned words and phrases

Cut unless quoted as examples or discussing the word itself.

## Vocabulary — cut

delve, foster, leverage (verb), utilize, facilitate, empower, streamline, robust (non-engineering), cutting-edge, paradigm shift, game changer / game-changing, this is huge, this changes everything, tapestry, realm, beacon, multifaceted, meticulous, intricate / intricacies, paramount, transformative, elevate, embark, supercharge, harness, ever-evolving, landscape (figurative), testament (to), vibrant, pivotal, crucial (as filler), underscore / underscoring, interplay, bolster, garner, commence, encompass, groundbreaking, seamless, navigate (figurative), showcase / showcasing, highlighting (puffery), unprecedented, profound (filler), synergy, pain points, value add, thought leadership, spearheading, aforementioned, endeavour/endeavor.

## Tech metaphor jargon — prefer concrete

substrate → base; wedge → add / entry; vector → way / method; locus / vantage / nexus → the real place or view; primitive (as noun) → name the thing; harness (metaphor) → use; surface ("API surface") → API / endpoints; bedrock / scaffolding (metaphor) → foundation / structure with a real name; modality / paradigm → mode / approach; gold-plating → more than the job needs; ratchet (metaphor) → limit that only tightens / real mechanism name; evacuate (for moving code) → move out; endgame → last phase; north star → goal; flywheel → say the loop; load-bearing → say what depends on it; blast radius (outside incident/security writing) → what breaks and for whom; doing the heavy lifting → name what does the work; cosplaying as / costume of → is pretending to be, or say what it actually is; X is the new Y → state the change.

## Empty adverbs — cut when empty; KEEP when voice

Often empty: just, literally, simply, truly, fundamentally, importantly, crucially, inherently, inevitably, genuinely, deeply, structurally.

**Keep** when they mark real emphasis, contrast, or spoken rhythm: *actually*, *honestly*, *I think*, *maybe*, *to be honest*.

No absolute adverb ban.

## Model phrase frames (2026): rewrite the frame

Phrase frames a 2026 Graphite study measured far above human rates. Treat each as a pattern card, not a word ban: rewrite the frame, keep the content.

- **"Why X matters" / "this matters"** (Opus 5.5): show the consequence instead (pattern #10).
- **"X is more than a Y, it's a Z"** (Opus 5.5): say what X is (pattern #7 sibling).
- **"The X is not simply Y" / "does not establish"** (Astra): state the claim and its limit directly.
- **"rather than relying on"** (Astra): name the method used; drop the foil.
- **"looking ahead, the…"**: cut the opener; give the plan or date.
- **dependable, incredibly** (Opus 5.5, Gemini): cut, or replace with the measured fact.

Tells shift with each model release. Add frames when a second source confirms them; retire none just because one model stopped using them.

## Chatbot / email residue — cut

I hope this helps!, Let me know if you need anything!, Of course!, Certainly!, Great question!, You're absolutely right!, You're right to push back, Found the smoking gun!, As an AI…, As a language model…, I'd be happy to…, Please don't hesitate to reach out, I hope this finds you well / email finds you well, As per my last email (unless genuinely needed).

## Sentence openers — prefer not to start with

Certainly, Absolutely, Sure, Moreover, Furthermore, Additionally, Interestingly, Notably, Importantly, Indeed — especially stacked.

Model-first-word tells (DETECT signal, not a writing recipe): avoid defaulting reply starts to "Certainly," "Sure," "Great question!", "Here is…", "Title:", "Step:", "Creating…".
