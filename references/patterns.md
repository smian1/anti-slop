# Pattern cards

Load for Edit/Detect depth; SKILL.md already covers the non-negotiables.

## Content

| # | Pattern | Fix |
|---|---------|-----|
| 1 | **Puffery / significance inflation** — pivotal moment, testament to, indelible mark, evolving landscape, solidifies its position | State the fact; let the reader judge |
| 2 | **Name-dropping / over-attribution** — outlet lists without what was said | One source + what it reported |
| 3 | **Superficial -ing analysis** — highlighting, underscoring, showcasing, reflecting, fostering | Delete or replace with mechanism/consequence |
| 4 | **Promotional language** — nestled, breathtaking, renowned, must-visit, groundbreaking | Neutral concrete description |
| 5 | **Weasel attribution** — experts agree, studies show, industry reports suggest | Name the source or cut; ask if missing |
| 6 | **Formulaic challenges** — Despite challenges… continues to thrive | Specific friction or cut |
| 7 | **Binary contrasts** — Not X. It's Y. / not just X but Y | State Y |
| 8 | **Negative listing** — Not a X. Not a Y. A Z. | State Z |
| 9 | **Faux-insight / throat-clearing** — Here's the thing, What nobody tells you, Let me be clear | Cut setup; make the claim |
| 10 | **Importance-flagging / metadiscourse** — This matters. The key point is. As you can see. | Show consequence or delete |
| 11 | **Demonstrative kickers** — That instinct backfires. That is the whole point. | Cut or fold into prior sentence |
| 12 | **Clever metaphor flourishes** — "bug wearing the costume of…" | Plain statement |
| 13 | **Colon reveals as drama** — The best part: it learns. | Plain sentence; colons for lists/labels/quotes |
| 14 | **Fake-strong verbs / copula dodge** — serves as, stands as, boasts, features | Prefer is/has + real verb |
| 15 | **Synonym / elegant-variation cycling** | Repeat the clear word |
| 16 | **Rule-of-three padding** | Use the true count (1, 2, 4…) |
| 17 | **False ranges** — from X to Y with no scale | List topics directly |
| 18 | **False agency** — the decision emerges; the data tells us; the complaint becomes a fix | Name the human actor |
| 19 | **Narrator-from-a-distance** — Nobody designed this. People tend to… | You / named actor in the room |
| 20 | **Rhetorical setups** — What if I told you, Plot twist, Question? Answer. | Drop; state the point |
| 21 | **Dramatic fragment stacks / staccato drama** — X. And Y. And Z. That's it. | Complete sentences; one earned fragment OK |
| 22 | **Fake-profound / summary-recap endings** — In conclusion, Ultimately, deep mic-drop | End on last concrete point or next action |
| 23 | **Generic positive / outlook endings** — The future looks bright. | Specific plan or cut |
| 24 | **Section-closing local recap / Whether-summaries** | Delete redundant closer |
| 25 | **Treadmill / low density** — long restatement of one idea | Advance the claim or cut |
| 26 | **Say feeling not mechanism** — "SQL you can read", "close at hand" | Number, instruction, or mechanism |
| 27 | **Invented concept labels / grandiose stakes** — the supervision paradox; will define the next decade | Plain claim + scope |

## Style / formatting

| # | Pattern | Fix |
|---|---------|-----|
| 28 | **Em dash overuse** | None in short copy; sample may restore in essays; parentheses allowed |
| 29 | **Bold / emoji / title-case decoration** | Sentence case; prose over decorative bullets |
| 30 | **Inline-header lists** — **Performance:** Performance improved… | Prose, or bold lead that adds new detail |
| 31 | **Robotic rhythm / uniform paragraphs** | Vary length and shape |
| 32 | **Parataxis stacks** (long prose) — Short. Short. Short. | Connect with clauses/semicolons |
| 33 | **Correlative bloat** — not only… but also | Split or simplify |
| 34 | **Hedged confidence / qualifier stacks** | Take the position or cut |
| 35 | **Filler phrases** — in order to, due to the fact that | To / because / delete |
| 36 | **Chatbot residue** | Delete; answer directly |
| 37 | **Cutoff disclaimers** — While specific details are limited… | Find sources or remove |
| 38 | **Sycophantic tone** | Respond directly |
| 39 | **Answering objections nobody raised / argument residue** | Cut rebuttals to ghosts |
| 40 | **Placeholder / Mad Libs** — `[Your Name]`, `XXXX` | Fill or remove before ship |

## Forensic — DETECT only (do not teach as writing tips)

| # | Pattern | Action |
|---|---------|--------|
| F1 | **Citation markup leaks** — `citeturn0search0`, `contentReference[oaicite:…]`, `oai_citation`, Grok cards | Flag + strip |
| F2 | **UTM-from-AI** — `utm_source=chatgpt.com` etc. | Flag + strip |
| F3 | **Unicode obfuscation** — homoglyphs, zero-width, fancy dashes as evasion | Flag + strip; never recommend |
| F4 | **Reasoning-chain / draft residue** — visible chain-of-thought crumbs, leftover hedges | Flag; clean in Edit |
| F5 | **Sudden register shift** mid-piece | Note mixed authorship; don't flatten the human half |

## Soft preferences (not hard bans)

- **Wh-openers** in headlines: prefer subject-led. Real questions stay.
- **Passive**: prefer active; allow when actor unknown (methods OK).
- **One short punchy fragment**: keep if earned; flag stacks only.
